# Community visual workbench powered by PyAutoLens — 3D teaching, 31 products, bilingual UI

Hi PyAutoLabs team — thank you for PyAutoLens! I built an independent MIT-licensed visual workbench powered by it, and would love your feedback.

**[Repository](https://github.com/SiriusFzh/PyAutoLens-Workbench) · [Download v1.0.0](https://github.com/SiriusFzh/PyAutoLens-Workbench/releases/tag/v1.0.0) · [English / 中文 documentation](https://github.com/SiriusFzh/PyAutoLens-Workbench#readme)**

One local browser app for Mac / Windows: draggable 3D geometry, 32 controls, 31 scientific products, PNG/FITS/CSV exports and teaching quick fits. English by default, Chinese available.

![Completed synthetic-data quick fit](https://raw.githubusercontent.com/SiriusFzh/PyAutoLens-Workbench/main/docs/screenshots/04-quick-fit.jpg)

The scope is forward simulation and teaching, not a full research-inference frontend. 3D distances are illustrative; θE is an explicit input. Checked on Apple Silicon Mac; Windows was not rerun for this release. The README includes attribution, citation guidance and limitations. Packaging/docs used AI coding assistance.

Would this be useful as a community teaching resource? If you would welcome a documentation link PR, please let me know where it belongs.
